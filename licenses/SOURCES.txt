License provenance
==================

Package licenses are copied from the installed npm packages at build time.
The versions are recorded in the generated THIRD_PARTY_NOTICES.txt.
Shaka's full LICENSE and third_party/cml-cmcd/{LICENSE,NOTICE} are copied
verbatim, rather than reconstructing their embedded notices.

The files maintained in this directory have the following sources:

hls-embedded.txt
  Copyright and license comment blocks retained verbatim from hls.js 1.7.3
  dist/hls.mjs for utf.js, vtt.js, and the DASH Industry Forum CEA-608 parser.
  Package versions requiring these embedded notices are pinned by the build.
  mpegts.js 1.8.2's embedded es6-promise notice is copied from its published
  dist/mpegts.js.LICENSE.txt; the es6-promise and events MIT licenses are
  copied from the installed packages.

ass-compiler.txt
  ass-compiler 0.1.15:
  https://raw.githubusercontent.com/weizhenye/ass-compiler/242018274f8838e740081745d23f2c5e308175e9/LICENSE
  assjs 0.1.10 embeds ass-compiler but does not publish its build lockfile.
  The retained compiler code matches both 0.1.15 and 0.1.16. Its exact
  embedded version is not established; both carry the same MIT copyright.
  The license here was compared in full against the 0.1.15 source above.

qrcode-generator.txt
  https://raw.githubusercontent.com/kazuhikoarase/qrcode-generator/517b9e6c3882f3ad28e4f776bbf1e1495869dc4c/LICENSE
  The npm 2.0.4 distribution provides the copyright and MIT identifier in
  dist/qrcode.mjs, but omits a standalone license file.
